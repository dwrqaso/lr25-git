# Лабораторная работа №25: Изучение системы контроля версий Git

Данный проект создан в рамках выполнения лабораторной работы по изучению системы контроля версий Git.

## Структура проекта:
- `index.html` — основная страница разметки с согласованным заголовком;
- `style.css` — стили оформления страницы.

## Выполненные задачи:
1. Инициализация репозитория и базовый коммит.
2. Ветвление feature-styles и слияние Fast-Forward.
3. Моделирование параллельной разработки в ветке feature-hotfix и разрешение конфликта слияния.
4. Синхронизация с удаленным репозиторием GitHub.
